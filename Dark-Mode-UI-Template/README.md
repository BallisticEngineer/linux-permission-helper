# Engineer-Forge DarkModeUI

Reusable C#/.NET 10 WinForms controls and theme library used by Linux Permission Helper.

The library is under src/DarkModeUI and is consumed through a project reference. The source is provided as part of the Linux Permission Helper release; no Git submodule is required.
